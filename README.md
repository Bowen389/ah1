# AH溢价最低10% · 20万元模拟组合

[最新账户报告](reports/latest.md) · [每日候选与逐股因子](data/signals/) · [完整模拟账本](data/state.json) · [Actions](../../actions)

策略是 **AH溢价最低10%的A股**，不是换手率策略。每个A股月末两地收盘后，按 `A股收盘价/(H股收盘价×港元兑人民币)-1` 升序，选 `ceil(合格股票数×10%)` 只。主板、非当时ST/退市名称、A股上市满365自然日；H股必须有当时的有效日线。次个A股交易日均分资金建仓，月末全部卖出。两地假期不同时统一使用此前最近共同交易日的A/H同日价格；停牌和缺数不填0。

## 首次启动

- 2026-10-28两地收盘后筛选、冻结候选。
- 2026-10-29首次以20万元现金启动模拟，首次有效任务在09:30—10:00内按**当时有效卖一报价**成交，受整手、资金和成交量限制；不会把延迟任务倒填为09:30开盘成交。
- 首次属于月中启动例外，2026-10-30月末退出；当天重新筛选，2026-11-02按新信号恢复完整月度持有。不要把首次两日持仓当作原始月度策略的独立验证。

## 模拟执行与资金

仅 `PAPER_ONLY`，代码没有券商连接、账户凭据或真实下单接口。初始200,000元，100股整手；每股均分净资产，不能买整手的资金闲置，不补选、不追单。买量不超过信号日前一交易日成交量与成交时累计成交量的1%；停牌、无卖一、涨停、过期或缺失报价不成交，残余持仓占用仓位。T+1，现金非负，重复任务不重复买卖。

费用沿用研究：佣金双边万一、每笔最低5元；过户费双边万0.1；**卖出印花税万一为用户研究自定义，并非法定税率**。实盘税率可另改配置，本仓不会悄悄切换口径。额外滑点0，但买入使用实际卖一而不是历史开盘价，所以模拟收益不会精确等于日线回测。

月末14:50/14:55提前冻结卖出意图；15:10/15:20用当日收盘价格近似结算已登记的意图。没有收盘前意图就不补造过去的收盘订单；任务错过、跌停或停牌则保留仓位并在后续交易日继续安排退出。日线收盘近似不证明真实集合竞价排队成交。

分红按登记日收盘持仓记录、除息日记应收；按研究保守扣20%红利税、现金和送转股假设延迟20个交易日可用，**不冒充券商真实到账/上市日期**。公开数据不能识别的配股或合并等复杂公司行动应暂停核对。账本保留所有权益和成交事件。

## 自动运行

GitHub Actions 北京时间09:31/09:36/09:41/09:51尝试模拟买入，14:50/14:55登记卖出，15:10/15:20结算与估值，16:35/16:45/16:55筛选及复查。仅需要公开行情，不需要Secret。全部写入`data/`与`reports/`并提交回main；并发锁防止多个任务冲突。

GitHub cron不保证准点。迟到超过10:00会记录错过买入，不回填历史成交；Actions失败及`reports/error_latest.md`可见。也可在Actions页面手动`Run workflow`，同样执行当前时段约束，无法通过参数伪造历史时点。2026交易日历依据上交所2025年第45号公告冻结，超过2026年会停止执行，须更新下一年官方日历后继续。

## 数据和限制

A/H映射和正式A股上市日期：东方财富`RPT_F10_ORG_BASICINFO`，每次真实筛选重新取得完整列表；A/H不复权日线与A股实时行情：腾讯；汇率：国家外汇管理局人民币汇率中间价，港币100外币单位除100；公司行动：东方财富`RPT_SHAREBONUS_DET`。当天价、上市日期、数据日期、汇率日期、选股排名均保存。外汇是同日共同正数，不影响截面排名。

历史研究2024-10-28—2026-10-27最低10%组合收益32.73%、最大回撤9.25%；当前主板名单和历史ST/退市覆盖不足，属于受限回测，不是收益承诺，也不是今天应买固定数量10只。月度分位持仓数量会变化。研究摘要见`docs/research_baseline.json`。

## 本地运行和检查

只使用Python3.11标准库，无`import os`，无第三方安装依赖。

```bash
python -m unittest discover -s tests -v
python main.py --phase auto
```

实际运行时读取北京时间，不接受历史日期执行参数。`data/state.json`为账户唯一事实来源，不应手工删除来重置历史；修复需保留事件并核对现金。原始截面数据在`data/raw/`，每次冻结信号均有SHA256。
